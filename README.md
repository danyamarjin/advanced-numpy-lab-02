# Лабораторная работа № 1 — Продвинутый NumPy

Пять задач: точность чисел, индексация, memmap и кэш, разреженные матрицы, Cython.

## Запуск

```bash
python -m pip install -r requirements.txt
python task1.py
python task2.py
ipython task3.py
python task4.py
python setup.py build_ext --inplace
python task5.py
```

Для сборки Cython нужен компилятор C (например, GCC или MSVC Build Tools).
Индексы NumPy начинаются с нуля; диапазоны в задаче 2.1 трактуются как включительные индексы.
В задаче 3 файл создаётся во временной папке и удаляется после выполнения. При запуске через IPython используется `%timeit`, при обычном запуске — `timeit.repeat`.
Обход строк C-contiguous массива обычно быстрее благодаря последовательному доступу к памяти. CSR экономит память при низкой плотности. Время зависит от оборудования, BLAS и нагрузки системы. В задаче 5 создание списка и массива не включено в измерение; сравниваются Python-цикл по списку и Cython-цикл по типизированному буферу с теми же значениями.
